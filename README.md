# Walmart Data Analytics Project

An end-to-end data analytics project focused on analyzing Walmart sales data to uncover **sales trends, branch performance, product insights, customer behavior, and revenue patterns**.

The project uses **Python, PostgreSQL** to perform data cleaning, exploratory analysis, business-focused SQL analysis, and interactive dashboard development.

## 🛠️ Tools & Technologies

* **Python** – Data loading, preprocessing, and analysis
* **Pandas** – Data manipulation and cleaning
* **PostgreSQL** – Database storage and SQL analysis
* **SQL** – Business queries and KPI analysis
* **SQLAlchemy & Psycopg2** – Python–PostgreSQL connectivity
* **Git & GitHub** – Version control and project management

## 📊 Key Analysis

The project analyzes:

* Year-wise and branch-wise revenue
* Sales performance and trends
* Product-line performance
* Customer purchasing behavior
* Payment method analysis
* Branch and category performance
* Revenue comparison between years
* Key business KPIs and sales insights

## 🔄 Project Workflow

**Raw Dataset → Python Data Cleaning → PostgreSQL → Business Insights**

## 🎯 Objective

The main objective is to transform raw Walmart sales data into meaningful business insights that can help understand **revenue trends, customer behavior, product performance, and branch-level sales performance**.

This project demonstrates practical skills in **Data Analytics, SQL, PostgreSQL, Python, and Business Intelligence**.
